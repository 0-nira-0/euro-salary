# Euro Salary

A web calculator for estimating net and gross salary in European countries with country-specific tax rules.

https://0-nira-0.github.io/euro-salary/

## Features

- Supports France, Germany, Spain, Italy, Belgium, and Poland
- Gross-to-net and net-to-gross calculation modes
- Adjustable parameters: employment type, family status
- Shareable URL with calculation state
- Available in multiple languages

## Tech Stack

- React 18, TypeScript
- Vite
- Tailwind CSS
- Zustand
- i18next
- Vitest

## Getting Started

```bash
npm install
npm run dev
```
